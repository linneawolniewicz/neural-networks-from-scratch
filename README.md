# neural-networks-from-scratch
Two implementations of simple feed-forward neural networks from scratch, to improve my understanding of backpropagation in practice. Networks are coded to classify MNIST using feedforward layers in NumPy.

The NN gif is from [this article](https://medium.com/data-science/lets-code-a-neural-network-in-plain-numpy-ae7e74410795) by Piotr Skalski.
